# Полная плита → Revit: состояние передачи 13.09.2026

Фронтенд не входит в эту работу. Добавлен отдельный конвейер:
`composite-plate-analysis/v1` → полный пакет → Full Plate Trial в pyRevit →
native Rebar → повторное считывание после Commit → обязательный откат → JSON.
Старый Core Trial и контракт `reinforcement-zone-revit/v2` не расширены и не сломаны.
Публичные модели ядра не менялись.

## Выполнено

- Экспорт всех выбранных зон четырёх направлений, включая два дополнительных
  компонента и нерегулярный шаг через несколько точных регулярных наборов.
  Повторная проверка осей, длины, количества и массы против исходного анализа.
- Выбор host и существующих RebarBarType в активной модели, без фиксированных
  ElementId тестовой плиты. Явные XY и глубины от верхней/нижней граней.
- Проверка консервативных оболочек стержней с cover против настоящего Solid,
  включая проёмы. Отказ целой партии, не обрезка и не экспорт только удобной части.
- Сверка физических стержней до и после Commit, откат всей группы при любой ошибке;
  Pending не объявляется успешным откатом. Ничего не сохраняется в RVT.
- Отдельная упаковка с белым списком. Панель MVP и её код сохранения не включены.

## Реальный пакет

`artifacts/revit_plate_trial/full-plate-trial.json` создан из полного реального
отчёта `artifacts/composite_plate_2026_09_13/real-full-1024-batch-verified.json`,
индекс фронта 10 (нумерация с нуля). 108 зон / 257 Rebar-наборов /
2531 физический стержень / 37 942,993252125 кг. Сохранены SHA256 исходного
анализа и все исходные блокеры. Выбор минимальной массы здесь диагностический,
не утверждённая «Точка 3». Требуются A500 Ø18/20/25/28/32/36.

В известный контур TEST_SLAB_01 при нулевом сдвиге и cover 25 мм не помещаются
990 стержней. Общий габарит тел 26 291,161 × 16 847,8865 мм больше плиты
23 600 × 14 000 мм — общий сдвиг проблему не решает. Геометрию рабочей
модели не подменяем этим прямоугольником; новый адаптер читает выбранный host.

## Что ещё не готово

**Это не постоянное размещение и не готовое целевое инженерное решение.**
Новый полный запуск ещё не выполнен специалистом на Revit 2024.
Источник остаётся исследовательским: выходы за контур, раскрой всей партии,
фазы/контакт фоновых и дополнительных наборов, Z-профиль, 3D-коллизии и
инженерная анкеровка не закрыты. Matching readback не меняет их статус.
Новая кнопка сама не исправляет исходные инженерные блокеры.

Ближайший необходимый шаг со стороны разработки — считать раскладку
непосредственно в контуре рабочей плиты с сохранением всей потребности, а
не доводить до размещения решение, рассчитанное без host. Если оно не
существует в текущем профиле прямых стержней, показать точные конфликтующие
КЭ/зоны и согласовать изменение ограничения; не подменять готовность обрезкой.
Реальные создание и выпуск требуют запуска Revit на Windows; локальные тесты
и IronPython без Autodesk API этого не подтверждают.

## Воспроизведение

```bash
PYTHONPATH=src python scripts/build_plate_revit_trial.py \
  --analysis artifacts/composite_plate_2026_09_13/real-full-1024-batch-verified.json \
  --candidate 10 --output artifacts/revit_plate_trial/full-plate-trial.json
PYTHONPATH=src python scripts/package_revit_plate_trial.py \
  --packet artifacts/revit_plate_trial/full-plate-trial.json \
  --output artifacts/revit_plate_trial/qmonitoring-full-plate-trial-0.6.0.zip
```

Команды создают только новые файлы; при повторении надо выбрать новое имя.
Материалы и готовый ZIP в Git не добавляются.
Инструкция специалисту: `integrations/pyrevit/FULL_PLATE_README.md`.

## Локальные проверки

48 новых тестов: полнота четырёх направлений, сохранность метрик/осей,
отклонение изменённых/неполных пакетов, 3D-readback, ошибки до/после Commit,
откат при сбое в середине партии, Pending, ветви Solid/проёмы/ошибка Boolean,
белый список ZIP и запрет перезаписи. Проверки Autodesk используют API-двойники,
а не реальный Revit. `scripts/verify_plate_revit_runtime.py` на CPython читает
реальный пакет всех 2531 стержня, проверяет арифметику, Unicode и отказ при
изменённой оси. Это не реальный readback модели.

Повтор на IronPython 2.7.12 в эту итерацию **не выполнен**: локальный Docker
не запущен, Colima останавливается с `disk colima in use by instance colima`.
Блокировку диска/данные виртуальной машины не удаляли. Новый runtime smoke
готов к запуску в прежнем окружении с `--require-ironpython`; до его успешного
запуска нельзя переносить прежний результат IronPython 0.5.1 на версию 0.6.0.

Полный набор на момент первого прогона: **1368 passed**, три известных
предупреждения openpyxl о колонтитулах. После дополнительных проверок пакета
и ветвей геометрии отдельно пройдены 48 новых тестов. `ruff`, `compileall`
и `git diff --check` прошли. Снимок выбранного host и доступных типов
сохраняется до блокирующего выбора профиля; даже setup-отчёт полезен для
последующего расчёта с геометрией рабочей плиты.
