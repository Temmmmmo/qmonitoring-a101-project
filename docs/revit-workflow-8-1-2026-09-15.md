# Сверка Revit с разделом 8.1 ТЗ

Первичный источник: `Техническое_задание_А101_ТЗ_Техлаб_2026.pdf`, PDF-страницы 13–14.
Текст извлечён Poppler и проверен по изображениям обеих страниц. Это раздел
пользовательского сценария; он требует выбранные семейства на текущем виде,
а не обязательно `DB.Structure.Rebar` в каждом пункте. Вводный абзац раздела
отдельно упоминает чертежи и 3D-модели; нынешние view-family экземпляры не закрывают 3D.

## Матрица требований

**Полный гейт 8.1 не закрыт.** Это первый проверяемый программный срез, допускаемый
к коммиту с честным `live_workflow_verified=false`. Старый Plan Preview 0.2.2,
его четыре графических вида и поддержка старых пакетов не изменены.

## Договор семейства и стадия данных

Отдельных RFA в локальных материалах нет. Полученный `Шаблон РК Onefile_V2.rvt`
может содержать семейства, но без Revit их список/параметры не подтверждены.
Поэтому используются загруженные типы и явный выбор **параметров экземпляра**,
не перевод по предполагаемым именам и не изменение типов всего проекта.
Роль зоны — `OST_DetailComponents`, `CurveBasedDetail` или `ViewBased`; роль подписи
— `OST_GenericAnnotation`, `ViewBased`. Загружать свои RFA можно штатно средствами Revit.

Временное создание одного экземпляра нужно, потому что параметры типа не равны
параметрам экземпляра. После считывания выполняется полный rollback. Length-поля
требуют `StorageType.Double` и `SpecTypeId.Length`, количество — Integer, не Yes/No;
ID/подпись — String. Неоднозначные ID, повторное использование параметра и read-only
поля отвергаются. Значения длины переводятся из мм в футы ровно один раз.

Вход — неизменный `source-isofields-zones/v1`: `demand_bbox` остаётся пятном потребности,
размеры экземпляра берутся из **исходного** `components.bar_axis_bbox_mm`.
Это осевой прямоугольник после исходной анкеровки/раскроя, не AreaBoundary и не
представление 1135 обрезанных отрезков. Точные неравномерные оси и исходный рецепт
сохраняются в отчёте; условный шаг явно подписан, семейство не объявляется физическим.

## Транзакции и проверка

Только текущий горизонтальный план; модели с рабочими наборами не требуют удаления
наборов. Разрешены обычная модель, локальная рабочая копия, detached с сохранёнными
наборами; прямой central/cloud/server не поддержан этим bounded-срезом.
Нет вызовов Checkout/Save/Sync/переключения workset. Revit может заимствовать связанные
элементы сам, и локальный rollback не заявляется откатом центрального владения.

Новые экземпляры помещаются в одну Transaction внутри TransactionGroup. После
Commit вся последовательность исходных компонентов заново выводится из пакета,
проверяются число/ID/type UID/OwnerViewId, точки или концы линии, ориентация и
все связанные параметры. Assimilate вызывается только после проверки. Любой
отказ сохраняет ошибки и откатывает всю группу; неподтверждённый откат выделен отдельно.

Локально: 22 новых теста проходят, включая детерминированный code-only ZIP, подмену текста/размера/OwnerViewId,
потерю экземпляра после Commit, координаты и отмену. Python 2 grammar проходит.
Это тестовые двойники API, не Autodesk Revit и не инженерная проверка рисунка семейства.

## API первичные источники

Autodesk 2024 перечисляет перегрузки `NewFamilyInstance(Line, FamilySymbol, View)`
для линейных элементов узлов и `(XYZ, FamilySymbol, View)` для аннотаций в
[FamilyInstances](https://help.autodesk.com/cloudhelp/2024/ESP/Revit-API/files/Revit_API_Developers_Guide/Revit_Geometric_Elements/Family_Instances/Revit_API_Revit_API_Developers_Guide_Revit_Geometric_Elements_Family_Instances_FamilyInstances_html.html).
Тип значения проверяется по [Definition.GetDataType и SpecTypeId.Length](https://help.autodesk.com/cloudhelp/2024/ENU/Revit-API/files/Revit_API_Developers_Guide/Basic_Interaction_with_Revit_Elements/Parameters/Revit_API_Revit_API_Developers_Guide_Basic_Interaction_with_Revit_Elements_Parameters_Definition_html.html).

Пакет: `python scripts/package_revit_workflow.py --output <новый.zip>`.
ZIP содержит только whitelist кода, инструкцию и manifest SHA256; ни RVT, ни RFA,
ни DXF, ни JSON рабочей плиты туда не включаются.
