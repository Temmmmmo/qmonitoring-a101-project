# С1: web-сценарий и границы доставки · 15 сентября 2026

Исторический срез до восстановления покрытия. Актуальный результат 16 сентября,
приоритеты ограниченного MVP и новые Revit-пакеты описаны в
[проверке P0](mvp-priorities-2026-09-16.md). Публичная поставка четырёх DXF уже
отдельно разрешена пользователем и выполнена; прежний статус ожидания разрешения
ниже относится к моменту написания этого документа.

Главная страница ведёт в расчёт всей плиты: выбрать подтверждённый комплект,
запустить свежий анализ, посмотреть исходные изополя вместе с зонами и физическими
стержнями, затем проверить гейты и скачать JSON. С1 является выбором по умолчанию,
но без четырёх проверенных исходных DXF кнопка недоступна; К09 остаётся отдельным
доступным выбором, если его исходники установлены. Синтетический режим отделён.

Живой локальный отчёт `artifacts/s1_flat_mvp_2026_09_15/revalidated-v3/web-report.json`
показывает 196 исходных зон, 1897 физических стержней, 88 позиций и 22683,50 кг.
Ноль стержней вне внешнего контура после обработки не делает вариант инженерно
допустимым: 38 исходных КЭ имеют неполное геометрическое наличие стали, 552 —
неполное покрытие с контрольными 40d; безотходный раскрой 11700 мм не выполнен.
В условном research-профиле высот насчитано 1383 3D-пары добавок; это не чтение
фактических слоёв рабочего Revit. Проверка в открытой модели остаётся `not_checked`.
Эти числа берутся UI из нового отчёта, не вшиты в страницы. Исходный спрос сохранён.
Отверстия, перепады высоты и защитный слой вне плоского MVP; реальная геометрия Revit
не проверена. Отдельного эталона С1 нет: PDF охватывает С1+С2 вместе.

JSON изополей/зон или графической раскладки можно открыть в Plan Preview через
`/revit`. Это диагностический графический черновик, не создание Rebar и не разрешение
постоянного размещения. Полный отчёт хранит непрошедшие проверки и provenance.

Deploy допускает отдельные переменные S1 asset и SHA архива, но ничего не загружает.
Право передать исходные материалы в приватный Release ещё должно быть подтверждено
владельцем данных. Без переменных текущий volume не меняется; с ними установка
проверяет архив и оригинальные SHA, а запущенный API — доступность четырёх DXF.
