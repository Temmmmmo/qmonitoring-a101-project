## Что можно использовать сейчас

- Четыре реальных DXF + явные SHK/профили → полный исследовательский расчёт,
  составные дополнительные наборы, позиции спецификации, масса/количество,
  проверка партии раскроя и независимая проверка покрытия.
- Точный полный пакет 108 зон / 2531 стержень без подмены одной тестовой зоной.
  Full Plate Trial работает с выбранной плитой и реальными Rebar, но только
  с обязательным откатом; полный новый Windows-запуск ещё не подтверждён.
- JSON рабочей плиты → проверка всех граней/проёмов/объёма → явный перенос host
  в систему координат DXF → тот же полный расчёт. Работает и для setup-отчёта
  без создания арматуры. [Инструкция и результаты](working-host-and-stock-fit-2026-09-13.md).
- Устранение лишнего выхода за край из-за центрирования остатка длины;
  исходные 40d, спрос, количество и масса не ослабляются. На реальном кандидате
  эта гипотеза не устранила 990 стержней вне тестового контура.

## Что отделяет это от выпуска

| Работа | Состояние / необходимое действие |
| --- | --- |
| Рабочий host и привязка | Ждём JSON выбранной рабочей плиты. Проверить геометрию и XY; не использовать стенд 300 мм как фундамент |
| Допустимая полная раскладка в host | Текущий эталон не проходит край при фиксированных 40d. После получения host пересчитать; если конфликт останется, решать постановку анкеровки/потребности, не удалять КЭ |
| Осреднение и расчётная анкеровка СТО | Не реализованы как полный проверенный производственный сценарий; понижение исходной потребности автоматически не включено |
| Высоты, контакт, фон и 3D-коллизии | Числовой профиль для рабочей плиты не подтверждён. Проверки одного направления и чтение стержней не равны проверке всей плиты с фоном |
| Безотходный раскрой выбранной партии | Реальная точка 37,94 т не проходит. Проверка/ограниченный подбор есть; совместный результат с host и остальными правилами не получен |
| Постоянное размещение и обновление | Полный безопасный apply/update с идентификацией собственных элементов не завершён. Текущий Full Plate Trial всегда откатывает изменения |
| Оформление в Revit | Номенклатура в ядре есть; полноценные параметрические спецификации/марки/листы по шаблону в новом полном сценарии не завершены |
| Сквозная приёмка | Нужен успешный запуск на копии рабочей RVT, сверка геометрии/количеств/длин/массы/ведомостей и повторного запуска |
| PNG и все официальные гейты | PNG остаётся заготовкой; гейт с обязательными DXF **и** PNG не объявляется закрытым. Новые критерии после встречи не поступили |

Загибы, муфты и сварка не добавляются в объём работ: пользователь их не заказывал.
Ограничения и ошибки не скрываются ради даты сдачи. Готовность к постоянному
размещению нельзя включить одной галочкой или успешной проверкой сериализации.

## Следующий шаг после ответа специалиста

Проверить и подготовить присланный host уже готовой командой; запустить полный
расчёт в его контуре; сопоставить оставшиеся конфликты с конкретными КЭ и зонами.
Если формат/геометрия не поддержаны, получить точную диагностическую причину,
а не молчаливый bbox. Только после допустимой геометрии проверять реальные
наборы в Revit и доводить постоянное размещение/обновление/оформление.
