## Что изменилось и что остаётся непроверенным

Оба реальных отчёта 0.5.0 из `revit_info/050/` содержат 89 посещённых объектов,
но ни одного сохранённого треугольника. Поэтому по ним нельзя подтвердить привязку
мозаики. Файл локальной связи по SHA256 совпал с исходным DXF; это отдельный факт,
не доказательство геометрии или цветов CAD-кэша в RVT.

В 0.5.1:

- Чтение продолжается после неизвестного слоя и локальных ошибок API; ошибка и
  неполнота явно записываются. Общие ограничения ресурсов останавливают проход.
- В основной `triangles_mm` попадает только подтверждённый `KLEENKA`. Другие слои
  и неизвестные меши сохраняются отдельно. Цвет, материал, bbox или совпадение двух
  чтений не используются для автоматического переименования слоя.
- Записываются сырые GraphicsStyleId, материал/цвет, каталог слоёв, пути вложенности
  и преобразования. В 0.5.0 сырых ID не было: нельзя утверждать, что это был именно −1.
- Основной путь: `GetSymbolGeometry` + цепочка преобразований. Альтернативный:
  `GetInstanceGeometry` корневых вставок, далее вложенные symbol-цепочки. Корневая
  матрица не применяется повторно. `GetTotalTransform` остаётся только метаданными.
- Сравнение двух чтений учитывает все меши и кратность одинаковых треугольников,
  допускает другой порядок вершин, но не подбирает перенос/масштаб. Допуск 0,01 мм
  технический; независимая сверка с DXF по-прежнему использует 0,1 мм.

Каждый проход ограничен 20 000 треугольников всех слоёв, 5000 объектов/граней,
12 уровнями вложенности. Сравнение ограничено 1 000 000 проверок кандидатов.
Неполное чтение или лимит сравнения дают `not_checked`, не совпадение.

`mesh_read_complete=true` может сочетаться с `status=partial`, если неизвестны слои.
`cad_geometry_comparison.status=matches` не делает их известными и не разрешает
размещение. Альтернативный меш не подставляется в калибровку автоматически.

Разделение local symbol geometry / instance copy соответствует
[описанию Autodesk для Revit 2024](https://help.autodesk.com/cloudhelp/2024/ENU/Revit-API/files/Revit_API_Developers_Guide/Revit_Geometric_Elements/Geometry/GeometryObject_Class/Revit_API_Revit_API_Developers_Guide_Revit_Geometric_Elements_Geometry_GeometryObject_Class_GeometryInstances_html.html).
Наличие материала не доказывает принадлежность CAD-слою. Новый способ чтения тоже
может вернуть меши без слоя: тогда нужен анализ нового отчёта, а не изменение модели.

Реальный запуск 0.5.1 ещё ожидается. Автоматическое размещение из реального DXF,
фазы фоновой сетки/Ø25 и высотный порядок X/Y остаются за пределами этой поставки.

- Полный набор с optional SciPy: **733 passed**; интеграционные проверки отдельно:
  **361 passed**. Добавлено 33 проверки относительно 0.5.0.
- Копия без приватных материалов: **698 passed / 35 skipped**. Две новые условные
  регрессии используют исходные отчёты `050/` только при их наличии; синтетические
  проверки продолжения обхода работают и в публичном checkout.
- Настоящий IronPython 2.7.12: прежние проверки сериализации, файлов и trial-геометрии,
  новый сравнитель мешей; **13 Python-файлов компилируются**. Autodesk API в этом
  окружении нет; реальное чтение подтверждается только будущим запуском специалиста.
- Проверены неизвестный первый меш, ошибки отдельных мешей/вставок/граней, сохранение
  читаемого префикса, материалы/каталог, вложенные переносы и повороты, несовпадение
  двух чтений, дубликаты, NaN и лимиты. При одинаковой геометрии без слоя независимый
  DXF-checker остаётся `blocked`; для подтверждённого слоя синтетическая сверка проходит.
- Ruff, compileall, `git diff --check` и сверка `core-axis-trial.json` с ядром прошли.
- Отдельная симуляция масштаба исходника: 4225 треугольников и такой же дублирующий
  слой, два чтения по 8450 треугольников. Сравнение прошло за 12 675 проверок кандидатов;
  два синтетических JSON-payload занимают 5 752 764 байта. Это не реальное чтение Revit
  и не прогноз размера/времени полного отчёта специалиста.
- ZIP: **21 файл**, 60 880 байт, фиксированный allowlist, побайтовое совпадение
  с исходниками. Приватных входов/отчётов нет. Старые архивы и исходные JSON не изменены.
