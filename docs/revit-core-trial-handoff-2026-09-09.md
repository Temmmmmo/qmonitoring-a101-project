## Что считается успехом

Одна логическая зона, одна дополнительная схема, два разных Rebar-набора и шесть
физических стержней. Тип 165160 (18 A500), host 407801, длина каждого 5340 мм,
X=1280…6620; Y=1100/1200/1400/1500/1700/1800; Z=−34 мм на данной плите.
Оба ряда NumberWithSpacing @300, без крюков. Верхний cover до тела — 25 мм.
Масса из прочитанных осей по общей формуле — 63,9986184 кг.

`commit.status=committed`, `post_commit_comparison.status=matches`,
`group_rollback.status=rolled_back`, `restoration.verified=true`, без ошибок Commit.
Отказ второго набора не должен оставлять первый. Состав ID экземпляров/типов и снимок
плиты/ручного эталона после отката должны восстановиться.

Это проверка общего конструктора и передачи его параметров, **не результат GA**,
не использование исходного DXF и не назначение глобальной фазы для реальной плиты.
Гейты инженерной выдачи остаются закрытыми; фон и порядок X/Y не моделируются.
Параметры 40d здесь проверяют перенос существующей политики ядра, а не её инженерное
согласование. На момент отправки версии 0.4.0 реальный запуск ещё ожидался.
