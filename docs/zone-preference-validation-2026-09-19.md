# Как устроена регрессия выбора вариантов

Проверено по коду и сохранённым отчётам 19 сентября 2026 года. Модель
`ridge-mass-bars-alpha-0.01/v1+bef6d63ed7e2` ранжирует уже рассчитанные варианты.
Она не строит зоны и не обучена предсказывать инженерную «Точку 3».
Инженер может выбрать любую точку доступного фронта независимо от подсказки.

## Данные и единица наблюдения

Использованы три инженерские выдачи из одного контекста К09:

| Выдача | Масса добавок по спецификации, кг | Физические стержни, шт. | Точки обучающего фронта v3 |
| --- | ---: | ---: | ---: |
| Плита над −2 | 3260,62 | 856 | 121 |
| Плита нуля | 3177,64 | 1019 | 139 |
| Типовая плита над 3–14 | 2878,76 | 1227 | 140 |

Это 400 строк кандидатов, но только три инженерские выдачи, а не 400 независимых
примеров и не три независимых здания. Направления одной плиты не разделяются
между обучением и проверкой. Входы 3-го и 9-го этажей относятся к одной выдаче.
Для С1 нет отдельной сопоставимой метки: PDF объединяет С1 и С2.

Инженеры не размечали число зон или предпочтительные точки наших фронтов.
Итоги спецификаций являются слабыми метками: совпадение массы и числа стержней
не доказывает совпадение узлов. В частности, описание готового К09 явно указывает
на гнутые стержни в инженерном эталоне, тогда как поиск выдаёт прямые зоны.

## Признаки, цель и обучение

Для кандидата i используются масса M_i после общей детализации с 40d и
каталогом длин и число физических стержней B_i. Минимумы берутся отдельно
по всему переданному фронту этой плиты:

```text
x_i = [1, M_i / min(M) − 1, B_i / min(B) − 1]

y_i = 0,5 × |M_i − M_инженера| / M_инженера
    + 0,5 × |B_i − B_инженера| / B_инженера
```

Число зон и число позиций спецификации не входят в признаки. Коэффициенты 0,5
в целевой функции выбраны нами для эксперимента, а не получены от инженеров.
Абсолютное отклонение штрафует и уменьшение, и увеличение относительно эталона.

Обучается линейная ridge-регрессия с фиксированным alpha = 0,01:

```text
beta = (Xᵀ W X + diag(0; 0,01; 0,01))⁻¹ Xᵀ W y
```

Свободный член не регуляризуется. Общий вес каждой инженерской выдачи одинаков;
вес строки равен `1 / (число выдач × отчёты этой выдачи × точки этого отчёта)`.
Таким образом, более длинный фронт не получает больший суммарный вес.

Полная модель имеет коэффициенты:

```text
score = 0,2494728494
      + 0,5590964880 × (M_i / min(M) − 1)
      + 0,4482342986 × (B_i / min(B) − 1)
```

Чем меньше score, тем выше подсказка. Показываются до трёх первых кандидатов;
при равенстве используются масса, число стержней и исходный индекс. Это
линейный компромисс массы и стержней, а не модель геометрии плиты или числа зон.
Изменение найденного фронта может изменить нормировку и порядок подсказок.

## Проверка без обучения на оцениваемой выдаче

Для каждого из трёх случаев отдельная модель обучена на двух остальных.
Все отчёты удерживаемого `case_id` исключаются вместе. При распознанном
отпечатке четырёх DXF и шкал приложение выбирает эту held-out модель;
для нового поддержанного входа использует полную модель.

Коэффициенты сохранены от фронтов v3, до конечной пересборки и bridge.
Повторное обучение на фронтах после пересборки дало худшую проверочную оценку,
поэтому новая модель не заменяла прежнюю. Ниже — повторная оценка сохранённых
held-out моделей на трёх более поздних фронтах, а не результат нового обучения:

| Выдача | Точек | Подсказка: зоны / кг / стержни | Ближайшая по слабой цели: зоны / кг / стержни | Regret |
| --- | ---: | --- | --- | ---: |
| Над −2 | 106 | 213 / 4071,73 / 1417 | 213 / 4071,73 / 1417 | 0 |
| Нуля | 124 | 255 / 4189,87 / 1616 | 255 / 4189,87 / 1616 | 0 |
| Над 3 | 122 | 282 / 2501,13 / 1754 | 209 / 2844,62 / 1633 | 0,10897 |

`Regret = y_выбранной − min(y)` на том же конечном фронте. Среднее — 0,03632;
для выбора минимальной массы — 0,05330, для геометрического колена — 0,33379.
Попадание в ближайшую по слабой цели точку: top-1 — 2/3, top-3 — 2/3.
На плите над 3 этажом ближайшая точка отсутствует даже в первых трёх подсказках.

Нулевой regret не означает совпадения с инженером. Например, для плиты над −2
сама слабая дистанция выбранной точки равна 0,45207. Здесь модель лишь выбрала
ближайшую из имеющихся альтернатив. Regret не является процентом ошибки массы,
производственным допуском или оценкой отставания от глобального оптимума.

Это исследовательская проверка на многократно использованных трёх случаях.
Хотя конкретная held-out модель не обучается на своей проверочной выдаче,
результаты этих же случаев уже использовались для выбора версии модели и
развития поиска. Поэтому оценка не является независимым финальным тестом;
нужны новые выдачи и предпочтения инженеров. Подсказка не подтверждает гейты:
во всех трёх приведённых отчётах проверка раскроя партии не прошла и
`placement_eligible=false`.
