## Доставка и повторение

Полный финальный JSON: `artifacts/k09_delivery_2026_09_16/dual-exterior-repair-v1/graphic-bar-plan-repaired.json`,
SHA256 `1be3cdbffb11faa5979729ba00f1a1a846c81d1237495cc863431d0ea1055c77`.
Полный web-report в той же папке, SHA256
`2b0f652d944eba48b4d646515119c9d15d1df7757613967ec2ccde07b93af0c0`.
Schema `graphic-bar-plan-repaired/v1`: immutable trim bytes/SHA, 900 baseline
операций retained и 18 явных additions, полный demand/lane manifest и свежие
whole-batch checks. Старые draft/pruned схемы не меняются.

В первой партии native preflight обнаружил один bottom-Y стержень
`source-recovery-1/0/8`, выступающий за **верхний** внешний контур. Он не пропущен:
консервативная обрезка физически укоротила его на 3,6565 мм. Финальный весь batch
прошёл полный adapter + dual-exterior native `make_review_plan` preflight:
918 проверены, native rejects0. Проверка использовала XY0/0 и явно заданные
четыре диагностические глубины 50 мм с doubles типов; это не live Revit API
и не подтверждение совместности стержней при этих глубинах. Затем root отдельно
проверил весь план с профилем для передачи специалисту **50;70;50;70 мм**:
918 стержней, геометрический preflight pass. При максимальном Ø16 разнос X/Y
20 мм оставляет минимум 4 мм между поверхностями ортогональных стержней;
это геометрический факт, не подтверждение нормативного зазора. Actual Revit execution
и readback остаются `not_checked`, Keep/Save/Sync и approval здесь отсутствуют.

Первый запуск:

```bash
PYTHONDONTWRITEBYTECODE=1 PYTHONPATH=src artifacts/ga_solver_env/bin/python scripts/replay_k09_flat_repair.py \
  --inputs '<каталог четырёх исходных DXF К09 над 3 этажом>' \
  --host qmonitoring-working-host-20260914-122250-368000.json \
  --output artifacts/k09_delivery_2026_09_16/fresh-noholes-repair-v1
```

Повторная обязательная внешняя обрезка, без GA:

```bash
PYTHONDONTWRITEBYTECODE=1 PYTHONPATH=src artifacts/ga_solver_env/bin/python scripts/replay_k09_dual_exterior.py \
  --inputs '<тот же каталог DXF>' \
```

Application integration доступна явно:
`analyze_engineering_example(..., outer_only_repair=True, working_host_bytes=..., confirm_identity_xy=True)`.

В этом срезе пользовательская доставка — offline JSON + совместимый Review plugin;
новый application mode ещё не выведен отдельным параметром web API/UI.
