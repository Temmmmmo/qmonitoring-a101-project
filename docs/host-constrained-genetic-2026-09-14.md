# Проверка реального host до генетического поиска

Добавлен opt-in `GeneticParetoOptimizer(candidate_guard=...)`. Фильтр проверяет
полную геометрию всех источников кандидатов до эволюции и после рекомбинации.
Исходные КЭ и атомы покрытия не удаляются. Если оставшийся конечный пул не покрывает
все атомы, возвращается явный отказ этого пула без запуска GA. После материализации
и фазовой обработки геометрия проверяется повторно. По умолчанию guard отсутствует:
прежние RNG/кандидаты/метрики не меняются.

`services/host_search_domain.py` независимо строит оптимистическую область
достижимости для любых осей в **явно указанной контрольной модели**: прямые стержни,
полные40d, заданные рецепты, конечная поперечная полоса обслуживания, материал,
общий для всех высотных сечений. Учтены внутренние отверстия, выемки, вырожденные
линейные области и численные допуски. Отрицательный результат относится только
к этой модели, не к невозможности армировать реальную плиту по иным узлам/расчёту.

## Реальный контрольный запуск

`artifacts/host_constrained_ga_2026_09_14/host-first-v1.json`, 77,892 секунды.
Неизменный исходный кандидат `plate:52`, рабочий Solid из probe14сентября,
нулевой сдвиг XY задан явно. Пул128 укрупнений, без рекомбинации;8 особей,
3 поколения,seed7,60с на направление. Исходный спрос сохранён полностью.

| Направление | Кандидаты до/после guard | Непокрытые атомы конечного пула | Недостижимые КЭ в отдельной оптимистической модели |
| --- | ---: | ---: | ---: |
| Низ X | 380 /162 | 211 | 45 |
| Низ Y | 253 /90 | 189 | 53 |
| Верх X | 533 /140 | 357 | 106 |
| Верх Y | 555 /198 | 316 | 77 |

Первые два числовых столбца относятся к конкретному пулу и фильтру, последний —
к другому, необходимому геометрическому условию. Их нельзя отождествлять.
Контрольный guard требует помещения и равномерного source-представления, и его
фактической STO-конверсии: он консервативнее проверки только исполнительных осей.
В этом запуске дополнительная асимметричная подгонка ещё не применялась.

Ни одно направление не получило полного кандидата; эволюция корректно не стартовала.
Нет частичной «маленькой массы», нового фронта, готового Revit-пакета или заявления
о прохождении инженерных гейтов. Положительные синтетические сценарии покрыты
отдельными тестами; простое увеличение числа поколений при неполном пуле не решает
показанную проблему.
