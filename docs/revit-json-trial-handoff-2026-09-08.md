## Границы теста для разработчика

Это один прямой Top X набор, не выдача оптимизатора и не автоматическое армирование
плиты. Производственные контракты v1/v2 не принимаются; фазы фоновой сетки, X/Y-порядок,
схема 100/200 и составное покрытие по-прежнему не подтверждены. Гейт размещения не снят.
Входной образец воспроизводит подтверждённые параметры 0.2.2, включая точные 96,875 мм,
а не подменяет их номинальными 100 мм.

Успех требует одновременно: внутренний Commit=`Committed`, повторная сверка реальных
осей=`matches`, откат внешней группы=`RolledBack`, восстановление ID и эталона=true.
Новые предупреждения/ошибки отменяют внутреннюю транзакцию; текст сохраняется в отчёте.
Ни Commit внешней группы, ни Assimilate, ни сохранения модели нет.

Основание механизма — [Autodesk: TransactionGroup](https://help.autodesk.com/cloudhelp/2026/ENU/Revit-API-MainReference/files/html/f1113d30-4c36-7844-1537-aad7f095cea0.htm):
откат группы отменяет уже закоммиченные внутренние транзакции.
Синхронная обработка и запись ошибок основаны на
[Failure Handling Options (Revit 2024)](https://help.autodesk.com/cloudhelp/2024/PTB/Revit-API/files/Revit_API_Developers_Guide/Basic_Interaction_with_Revit_Elements/Transactions/Revit_API_Revit_API_Developers_Guide_Basic_Interaction_with_Revit_Elements_Transactions_Failure_Handling_Options_html.html)
и [Handling Failures](https://help.autodesk.com/cloudhelp/2014/DEU/Revit/files/GUID-52A45CC1-3BB4-48B4-BFC7-F6F8666C2AA4.htm).
Документация не заменяет запуск на целевом Revit 2024: его отчёт для 0.3.0 ещё ожидается.
