# Сообщение Revit-специалисту

Привет! Добавил исходную схему, по которой можно разбирать и размечать армирование:
цветные изополя, прямоугольники зон, номера и параметры наборов.

Отправляю Plan Preview 0.2.2 и `source-isofields-zones.json` для нашей плиты К09.
Установи новую версию расширения вместо предыдущего пути **QMonitoringPreview**;
остальные кнопки и рабочие наборы трогать не нужно. Инструкция лежит в ZIP.

Открой ту же локальную модель, выдели плиту и нажми **Plan Preview**. Выбери новый
JSON, новое имя отчёта и проверь предложенное смещение XY. Для этой схемы координаты
исходные, без ручной подгонки; нулевое смещение используй только если привязка совпадает.

Должны появиться четыре новых чертёжных вида: низ X/Y и верх X/Y.
Цвета — исходная потребность, синий контур — пятно зоны, фиолетовый — границы
исходного набора после удлинения и раскроя. Номера Z связаны с параметрами справа.
Это исходная разметка, не исправленная физическая арматура и не AreaReinforcement.

Пришли JSON и скриншот одного вида крупно. Если будет ошибка — полный текст.
При ошибке проверки программа должна откатить все четыре новых вида. RVT она сама
не сохраняет и не синхронизирует. Этот новый режим с цветными областями пока прошёл
локальные проверки; именно его первый запуск в Revit ещё нужно проверить.

Отдельно прикладываю `graphic-bar-plan-draft.json`: это новые физические отрезки после
обрезки по внешнему контуру и отверстиям. Открой его той же кнопкой отдельно от изополей.
Получится графический вид четырёх направлений, **не Rebar**. В заголовке указаны
оставшиеся замечания по покрытию, 40d, коллизиям и раскрою — обрезка их не отменяет.
