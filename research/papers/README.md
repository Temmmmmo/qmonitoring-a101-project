# Локальные PDF

В этой директории находятся скачанные открытые версии статей из
[`../README.md`](../README.md). Файлы `*.pdf` исключены из Git как тяжёлые бинарники, но
остаются доступны в локальной рабочей копии.

Перед использованием проверяйте лицензию и исходную страницу публикации. Не добавляйте
сюда материалы организаторов или файлы, полученные в обход платного доступа.
