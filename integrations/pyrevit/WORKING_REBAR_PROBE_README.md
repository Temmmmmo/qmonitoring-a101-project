# Working Rebar Probe — существующая арматура рабочей плиты

Это отдельная кнопка только для чтения. Она **не создаёт и не меняет арматуру**, не
открывает транзакций, не сохраняет и не синхронизирует RVT, не запрашивает владение
элементами и не открывает рабочие наборы. Удалять совместную работу не нужно.

## Как запустить

1. Распакуй архив в новую папку. В pyRevit → Custom Extension Directories добавь
   именно папку, **внутри которой** лежит `QMonitoringReadOnly.extension`, затем
   нажми Reload. **Старые пути QMonitoring не трогай**: прежние кнопки останутся
   на месте. Новая вкладка `QMonitoringReadOnly` независима от старой установки и
   содержит только одну кнопку чтения. Папки удалять или перезаписывать не нужно.
2. Открой рабочую модель с её обычными рабочими наборами. Выдели нужную плиту
   (ту же, которую читали Working Host Probe), либо выбери её после нажатия кнопки.
3. Нажми **QMonitoringReadOnly → Diagnostics → Working Rebar Probe**.
4. Выбери новое имя JSON и подтверди сбор. DXF и пакет раскладки здесь не требуются.
5. Пришли JSON разработчику. Статус `partial` тоже полезен: он означает явно
   записанные пробелы чтения. Не меняй модель ради исчезновения замечаний.
   При падении пришли полный текст ошибки из окна pyRevit.

## Что читается

- Только native `Rebar` и `RebarInSystem`, у которых `GetHostId()` указывает на
  выбранную плиту. Коллектор работает по документу, не по активному виду или рамке.
- Фактические включённые и исключённые положения наборов; проверяется согласие
  с `Quantity` и `NumberOfBarPositions`. Ключ положения — `UniqueId + position_index`.
  Родители Area/Path не прибавляются к числу стержней, а сверяются с их детьми.
- Настоящие оси в координатах Revit, в мм: отрезки и дуги, концы, длина, середина;
  у дуги также центр, радиус, нормаль, базис и угловые параметры. Диагностическая
  тесселяция записывается отдельно, не подменяет точную дугу. Уже выполненные Revit
  смещения набора и отдельных стержней повторно не применяются.
- Тип, номинальный и модельный диаметры, материал, Mark, встроенные параметры,
  ID формы/крюков, рабочего набора и строительных фаз; ID и UID плиты, модель,
  версия Revit, защитные слои. Геометрию solid берём из отдельного Working Host
  Probe с проверкой совпадения модели/плиты; в этом JSON её не дублируем.

## Что отчёт не доказывает

`collected` означает только полноту доступного native-инвентаря выбранной плиты в
рамках поддержанных классов и установленных лимитов. Это не проверка несущей
способности, потребности, анкеровки, коллизий или разрешение на размещение.

Фон, дополнительная и краевая арматура остаются **не классифицированы**: по одному
диаметру, Mark или форме это не определяется. Значение 531 относится к гнутым
стержням спецификации PDF; наличие такого количества объектов в RVT ещё не
установлено. Сбор не означает согласия на гибридное решение или генерацию загибов.

Высоты сохраняются как реальные XYZ, но слой «верх/низ», направление и фаза
раскладки не назначаются автоматически. Один гнутый стержень может иметь ветви
на разных высотах. `CreatedPhaseId` — строительная фаза Revit, не фаза шага сетки.

Закрытые user worksets, недоступные родители/положения, нестандартные кривые и
достигнутые лимиты дают `partial`; полный физический счётчик тогда неизвестен.
Доступные уже прочитанные объекты остаются в отчёте, не выдаются за всю партию.
Арматура Fabric/RebarContainer выбранной плиты обнаруживается, но её оси пока не
снимаются — это тоже `partial`. Связанные модели и стержни других hosts не входят
в геометрию этого инвентаря, даже если визуально пересекают плиту. Поэтому отчёт
не является полным входом проверки всех коллизий здания. Видимость на активном
виде, скрытые категории и его фильтры не являются фильтром отбора стержней.

Модель с нулём Rebar может честно вернуть ноль только после успешного чтения
всех поддержанных разделов. Area/Path без физических детей не трактуется как ноль.
Чтение не включает сохранённую RVT-копию или её байтовый хеш: идентификаторы и
метаданные относятся к текущему открытому документу, включая несохранённое состояние.

## Проверка и API

Локальные тесты используют заменители Revit API и проверку синтаксиса Python 2.
Это не запуск Autodesk/IronPython: нужен первый реальный запуск в Revit 2024.
В коде нет вложенных comprehensions, на которых ранее падал IronPython 2.7.
JSON сохраняется через уже проверенный в Revit UTF-8 writer без ASCII-перекодировки.

Основной контракт фактических осей подтверждён
[Autodesk Revit 2024 — Rebar, Geometry](https://help.autodesk.com/cloudhelp/2024/ENU/Revit-API/files/Revit_API_Developers_Guide/Discipline_Specific_Functionality/Structural_Engineering/Structural_Model_Elements/Reinforcement/Revit_API_Revit_API_Developers_Guide_Discipline_Specific_Functionality_Structural_Engineering_Structural_Model_Elements_Reinforcement_Rebar_html.html).
Представление дуг описано в
[Mathematical representations of curve types](https://help.autodesk.com/cloudhelp/2024/ENU/Revit-API/files/Revit_API_Developers_Guide/Revit_Geometric_Elements/Geometry/GeometryObject_Class/Curves/Revit_API_Revit_API_Developers_Guide_Revit_Geometric_Elements_Geometry_GeometryObject_Class_Curves_Mathematical_representations_of_curve_types_html.html),
чтение состояния рабочих наборов — в
[Worksets](https://help.autodesk.com/cloudhelp/2024/ENU/Revit-API/files/Revit_API_Developers_Guide/Advanced_Topics/Worksharing/Revit_API_Revit_API_Developers_Guide_Advanced_Topics_Worksharing_Worksets_html.html).

Архив содержит только кнопку, три её runtime-зависимости, инструкцию и manifest
с SHA256 каждого файла. Исходные RVT/DXF/PDF и команды создания в пакет не включены.
