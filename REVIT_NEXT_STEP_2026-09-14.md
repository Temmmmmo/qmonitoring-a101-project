# Следующий запуск на рабочей плите

Отправить архив:
`artifacts/revit_working_host_2026_09_14/qmonitoring-working-host-probe-0.1.0.zip`.
Внутри новая кнопка только чтения, инструкция и контрольный `source/top-X.dxf`
именно для плиты над 3-м этажом. Старый `full-plate-trial.json` не нужен.

## Сообщение специалисту — можно скопировать

Привет! Геометрию рабочей плиты получил, спасибо. Проёмы и защитные слои
прочитались. Теперь хочу проверить в одном отчёте именно эту плиту и её DXF.

Подготовил отдельную кнопку Working Host Probe: она только читает модель,
арматуру не создаёт, типы и глубины вводить не нужно.

1. Распакуй новый архив. В настройках pyRevit замени старый путь QMonitoring
   на папку, внутри которой лежит новая `QMonitoring.extension`, и нажми Reload.
2. Открой копию `VTNK-02_RD_KR_K09_KJ2.3-14.rvt` и выдели ту же плиту
   `Пм-1`, ElementId `11020633`.
3. Нужен DXF верхнего X этой рабочей плиты. Точный исходный файл приложил
   как `source/top-X.dxf`. Если он уже есть в модели — используй существующий
   импорт/связь. Если нет — свяжи приложенный файл с подходящими единицами
   и размещением. Старый DXF тестовой плиты здесь не подходит.
4. Нажми **QMonitoring → Diagnostics → Working Host Probe**, выбери нужный
   DXF из списка и новое имя JSON. В дополнительном окне исходного DXF
   укажи приложенный `source/top-X.dxf`.

Пришли полученный JSON. Если статус `partial` — тоже присылай, разберу причины
сам. Если будет падение — нужен полный текст ошибки. Кнопка ничего в RVT
не меняет и не сохраняет.

## Для нас

Это проверка привязки, не новый запуск создания 902 стержней. При гипотезе
нулевого сдвига текущая партия не проходит границы/отверстия рабочей плиты.
Сначала связываем правильные исходники с моделью, затем перераскладываем
с учётом подтверждённой геометрии. [Подробные результаты](docs/revit-working-solid-2026-09-14.md).
