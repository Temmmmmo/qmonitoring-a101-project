Проверить JSON из Revit

Можно загрузить один отчёт или оба. Два файла позволяют сопоставить идентификаторы плиты и модели. Это проверка переданных записей, без подключения к текущему RVT.

До 32 MiB суммарно. Исходные JSON не сохраняются приложением и не публикуются по ссылке. Не загружайте чужие или не разрешённые к передаче материалы.

Установка без замены старых кнопок

  1. Скачайте нужный ZIP и распакуйте его в новую папку на компьютере с Revit.
  2. В pyRevit → Settings → Custom Extension Directories добавьте родительскую папку: внутри неё должна лежать папка с окончанием .extension.
  3. Нажмите Reload. Откройте новую вкладку, указанную на карточке инструмента.

Добавить этот путь:C:\QMonitoring\WorkingRebar\Внутри него:QMonitoringReadOnly.extension\

Не выбирайте ZIP или script.py. Удалять рабочие наборы и отключать старые QMonitoring-вкладки не нужно. При обновлении заменяйте только путь предыдущей версии этого же расширения.

Где заканчивается установка и начинается инженерная проверка

В этих ZIP нет моделей, исходных DXF, частных отчётов или готовой раскладки. Читающие кнопки ничего не меняют в RVT; графический просмотр создаёт новый вид только после подтверждения.

Статус collected означает успешный сбор данных, не пройденные инженерные гейты. partial — полезный отчёт с явными пробелами чтения, его не нужно исправлять изменением модели.

Общий JSON составного расчёта пока не является пакетом для Plan Preview. Автоматическое создание арматуры с новыми формами и проверка всех коллизий здесь не заявлены.

Отчёты могут содержать геометрию, имена и пути модели. Передавайте их только участникам проекта.
