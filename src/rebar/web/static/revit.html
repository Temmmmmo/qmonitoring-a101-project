Глубины осей: что вводить

В Rebar Review глубины предлагаются автоматически по native-граням и максимальным диаметрам выбранных типов. Подтвердите предложение; ручной ввод нужен только через «Другие настройки». Профиль MVP: отступ тела от грани 40 мм и межслойный зазор 4 мм, без использования Revit cover. Глубина — расстояние от native-грани плиты до оси (центра) стержня, в миллиметрах: для нижней арматуры от нижней грани внутрь, для верхней — от верхней внутрь. Это не защитный слой (cover), не XY-перенос и не высота из DXF.

Порядок ввода: низ X; низ Y; верх X; верх Y. Только для диагностической копии К09 Пм-1, native Floor ID 11020633, толщина 200 мм: при максимальных диаметрах низ 12 / верх 16 мм предложение — 46;62;48;68 мм. Оси X ближе к граням, оси Y глубже — так ортогональные стержни разделены по высоте.

0 ставит ось на грань: часть тела стержня окажется снаружи, и вся партия блокируется. Этот пример не универсальная настройка, не норматив и не инженерное подтверждение. Для другой плиты нужен собственный профиль глубин; отверстия, cover и все коллизии этим примером не проверены.

Проверить JSON из Revit

Можно загрузить один отчёт или оба. Два файла позволяют сопоставить идентификаторы плиты и модели. Это проверка переданных записей, без подключения к текущему RVT.

До 32 MiB суммарно. Исходные JSON не сохраняются приложением и не публикуются по ссылке. Не загружайте чужие или не разрешённые к передаче материалы.

Установка ZIP

  1. Скачайте нужный ZIP и распакуйте его в новую папку на компьютере с Revit.
  2. В pyRevit → Settings → Custom Extension Directories добавьте родительскую папку: внутри неё должна лежать папка с окончанием .extension.
  3. Нажмите Reload. Откройте новую вкладку, указанную на карточке инструмента.

Добавить этот путь:C:\QMonitoring\WorkingRebar\Внутри него:QMonitoringReadOnly.extension\

Не выбирайте ZIP или script.py. Удалять рабочие наборы и отключать старые QMonitoring-вкладки не нужно. При обновлении заменяйте только путь предыдущей версии этого же расширения.

Ограничения и другие технические режимы

Границы результата

В этих ZIP нет моделей, исходных DXF, частных отчётов или готовой раскладки. Читающие кнопки ничего не меняют в RVT; графический просмотр создаёт новый вид только после подтверждения.

Статус collected означает успешный сбор данных, не пройденные инженерные гейты. partial — полезный отчёт с явными пробелами чтения, его не нужно исправлять изменением модели.

Общий JSON составного расчёта не является пакетом для Plan Preview. Используйте кнопку «Скачать изополя + исходные зоны» на странице расчёта плиты. Автоматическое создание арматуры с новыми формами и проверка всех коллизий здесь не заявлены. Flat MVP использует внешний контур DXF без отверстий, перепадов и защитного слоя — это не измеренный Revit-host.

Отчёты могут содержать геометрию, имена и пути модели. Передавайте их только участникам проекта.
