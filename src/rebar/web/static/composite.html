Первый раз? Посмотрите готовый пример

Ничего выбирать или загружать не нужно. Рассчитаем синтетическую плиту 6 × 4 м: четыре направления, варианты раскладки, позиции и проверка раскроя. Проверки не отключаются ради демо — ограничения будут показаны в результате.

После расчёта переключайте «Низ · X / Y» и «Верх · X / Y», сравнивайте варианты и откройте «Общая ведомость позиций».

Рассчитать свои DXF — файлы и параметры проекта

1. Исходные DXF и шкалы

Excel не нужен. Для каждого направления укажите его DXF и соответствующую шкалу SHK. Поддержанный профиль: фон @300, до двух добавок @300 или условного @150 (оси 100/200), либо одна добавка @100 по схеме касания фона из СТО. Неподдержанную схему программа отклонит, а не заменит другой.

2. Параметры раскладки

Начало фона — глобальная поперечная координата в мм (для X это Y и наоборот). Первая добавка @150 автоматически следует подтверждённой схеме 100/200 относительно фона. Для первой @300 и второй добавки задайте смещение относительно начала фона. Пустые поля не заменяются нулём. Эти параметры не означают инженерного согласования.

Пока используется контрольная анкеровка 40d с каждого конца. Осреднение по СТО не применяется. Для @100 принята схема касания при одинаковой высоте осей: смещение рядом с фоном равно половине суммы диаметров. Высоты и фактический контакт ещё требуют совместной проверки. Подбор длин — только вверх и без добавления стержней; при превышении лимита массы вариант отклоняется. Это ограничение к исходному кандидату, не сравнение с инженером. Проверка партии использует смешанные отрезки одного диаметра и класса из прутка 11700 мм при нулевом пропиле; допущение явно сохраняется в отчёте.

3. Проверка границ плиты

Необязателен для расчёта вариантов, обязателен для проверки границ. Проверяется прямоугольная плита с прямоугольными сквозными проёмами. Другая геометрия отклоняется. Краевой спрос не удаляется, стержни не обрезаются. Снимок не заменяет актуальную проверку модели.

Результат всей плиты

Это расчётные варианты, не разрешение размещения. Высоты слоёв, фон и общие 3D-коллизии не подтверждены. Revit-модель не меняется.
