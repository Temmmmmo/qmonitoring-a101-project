Отдельный пересчёт К09 по границам рабочей Revit-плиты

Обычный пример использует границу DXF. Этот режим использует границы настоящей плиты из отчёта Working Host Probe. Нужна плита К09 толщиной 200 мм и совпадение координат. Стержни ограничиваются контуром, затем покрытие проверяется заново. Отверстия и защитный слой в MVP не учитываются; 40d и раскрой проверяются отдельно.

Программа предлагает раскладку, конструктор проверяет её перед применением. Результаты проверок показаны рядом с вариантом.

Что такое фон, добавки и варианты?

Фон — основная сетка арматуры, предусмотренная проектом. Программа рассчитывает добавки там, где этой сетки недостаточно; сам фон не создаёт и не заменяет.

Варианты — разные раскладки по одной исходной потребности. Сравнивайте массу, число отдельных стержней и число позиций — разных типоразмеров в ведомости. Более лёгкий вариант не обязательно удобнее в монтаже. Проверки относятся к выбранному варианту.

Для готовой плиты ничего про фон вводить не нужно. Для своего проекта его положение нужно знать, чтобы поставить добавки относительно основной сетки. Наличие фона в модели и все его пересечения с добавками сайт автоматически не проверяет.

1. Исходные DXF и шкалы

        
Excel не нужен. Для каждого направления укажите DXF и соответствующую шкалу: файл .shk или PNG с цветной легендой вверху.
          Поддержанный профиль: фон @300, до двух добавок @300 или условного @150 (оси 100/200),
          либо одна добавка @100 по схеме касания фона из СТО.
          Неподдержанную схему программа отклонит, а не заменит другой. Действующая область каждой зоны
          ограничена цветными КЭ: белые промежутки и вырезы исключаются из зоны. Прямоугольник остаётся
          поисковым окном; физические стержни требуют отдельной проверки.

        

      

      
Привязка к фоновой сетке · только для своего проекта
      
2. Где проходят фон и добавки

        
Эти поля нужны только при загрузке своих файлов. Изополе задаёт потребность, но не всегда
          положение отдельных стержней. Возьмите координату фоновой сетки из проекта.

        
Пример: фон @300 с началом 0 проходит через 0, 300, 600 мм.
          Добавка @300 со сдвигом 100 проходит через 100, 400, 700 мм.
          Для X-стержней эти координаты отсчитываются по Y, для Y-стержней — по X.
          Это положение в плане, не границы плиты и не глубина по высоте.

        
Первая добавка @150 размещается по схеме 100/200 между фоновыми осями;
          поле сдвига первой @300 на неё не влияет. Сдвиг второго набора используется, только если
          он есть в шкале. Ноль — конкретная координата; пустое поле означает неизвестную привязку.

        

        

          
          
          
        

        
Настройки поиска и раскроя · можно оставить стандартные
        
Они влияют на время поиска и форму вариантов, а не изменяют исходную потребность.
          Больше предложений и времени — шире поиск, но это не гарантия лучшего результата.
          Лимиты зон и позиций ограничивают сложность раскладки; слишком малые лимиты могут исключить решение.

        

          
          
          
          
          
          
          
          
        

        
Пока используется контрольная анкеровка 40d с каждого конца. Осреднение по СТО не применяется.
          Для @100 принята схема касания при одинаковой высоте осей: смещение рядом с фоном равно
          половине суммы диаметров. Высоты и фактический контакт ещё требуют совместной проверки.
          Подбор длин — только вверх и без добавления стержней; при превышении лимита массы вариант отклоняется.
          Это ограничение к исходному кандидату, не сравнение с инженером. Проверка партии использует смешанные отрезки одного
          диаметра и класса из прутка 11700 мм при нулевом пропиле; допущение явно сохраняется в отчёте.

        

      

      
3. Дополнительная проверка прямоугольной плиты

        
        
        
Этот отдельный режим принимает Reference Probe для прямоугольной плиты с прямоугольными проёмами.
          Другую геометрию он не поддерживает и стержни не обрезает.
          Для готового К09 используйте пересчёт по Working Host выше; это другой режим.
          Без отчёта для своего проекта можно рассчитать варианты, но границы Revit-плиты не будут проверены.
